# ととのうToDo

期限、タグ、依頼元・依頼先、添付ファイルをひとつに整理できる個人向けToDoツールです。PCとスマートフォンの両方で利用できます。

## 主な機能

- ToDo登録日時の自動記録
- 期限と状態（未着手・進行中・確認待ち・完了）の管理
- 一覧・かんばん・ガントチャートの3つの表示切替
- タブとToDoカードのドラッグ＆ドロップ並び替え（PC・スマホ対応）
- ToDoタイトルのダブルクリック直接編集
- かんばん上での状態変更（PCはドラッグ、スマホは選択式）
- 日付のみを標準にし、必要な場合だけ時刻を追加できる開始日・期限日
- 開始日と期限日を使った14日間のガントチャート
- 「すべてのToDo」ボタンによる絞り込みの一括解除
- 作成・改名・削除できるカスタムタブと、ToDoごとの所属タブ設定
- タグ、依頼元、依頼先、メモの登録
- ファイル添付と再ダウンロード
- 一覧・かんばんカードへのスクリーンショット画像の貼り付け（Ctrl＋V）
- 添付・タブ・ゴミ箱・テンプレートを含むバックアップと復元
- 添付画像のプレビューと端末内の保存容量表示
- ゴミ箱、削除直後の取り消し、完全削除
- 画面内・ブラウザ通知による日時リマインダー
- 毎日・毎週・毎月の繰り返しToDoと定型テンプレート
- 今日、期限超過、今後7日、完了済みの集計
- タイトル、タグ、依頼元・依頼先を横断する検索
- PC・スマートフォン向けのレスポンシブ表示
- メールリンク認証によるPC・スマートフォン間の自動同期
- 本人専用のクラウドデータと非公開の添付ファイル保存

## データの保存場所

ToDo・タブ・子ToDo・テンプレートはSupabaseへ、添付ファイルはSupabaseの非公開Storageへ保存します。PCとスマートフォンで同じメールアドレスのログインリンクを開くと、同じデータを利用できます。

ブラウザのIndexedDBにも端末内キャッシュを保存するため、一時的に通信できない場合も編集できます。通信復旧後に自動同期し、別端末の更新は20秒ごと・画面復帰時・オンライン復帰時に取得します。初回ログイン時は、ログイン前から端末にあるデータをクラウドデータと重複しないよう統合します。

重要なファイルの原本は別途保管し、必要に応じて「データ管理」からJSONバックアップも保存してください。Supabaseの設定手順と安全設計は [`docs/supabase-setup.md`](docs/supabase-setup.md) にまとめています。

### 画面デザイン

- 選択中のタブと絞り込み条件を、画面上部で常に確認できます。
- 一覧は期限・状態を横並びで比較しやすくし、選択したToDoの詳細を右側に表示します。
- スマホでは上部ナビゲーションと横スクロールできるタブ、画面下部の「追加」ボタンに切り替わります。
- 一覧・かんばん・ガントの表示切り替え、ドラッグ操作、タイトルの直接編集など従来の機能はそのまま利用できます。

公開用ファイルは `npm run build:pages` で `pages-dist` に生成します。
公開版のSupabase URLとpublishable keyはブラウザ向けの公開設定です。データはRow Level Securityで本人のログインIDに限定し、secret keyやToDo・添付ファイルをリポジトリへ保存しません。
